## 🚀 Quick starts

### C
```sh
cc -Wall -Wextra -std=c11 c/hello.c -o hello
./hello
```

### C++
```sh
cmake -S cpp -B build
cmake --build build
./build/hello_cpp
```

### Java
```sh
javac java/HelloWorld.java
java -cp java HelloWorld
```

### JavaScript
```sh
node javascript/hello.js
```

### HTML / CSS / JavaScript
Open [web/index.html](web/index.html) in a browser.

### Shell
```sh
bash shell/hello.sh
```
